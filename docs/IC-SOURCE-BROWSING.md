# CC-05: source browsing and cross-host catalog

Local implementation, 2026-09-15. Canonical acceptance and manual checks are in [IC's source-browsing plan](../../IdentityCenter/Documentation/Quality/source-data-browsing.md).

`Conduit.SourceBrowsing` owns the bounded sample/catalog contracts, known-secret field suppression and display limits. `IdentityCenter.Brand` owns `BrandSourceBrowser` and `BrandSourceCatalog`, composing its existing dialog, browse toolbar and list table. Both products have thin UI/service adapters. The shared Showcase `/objects` family renders both actual components with simulated data. No product-local CSS or duplicated browse form/table was introduced.

Conduit `SourceBrowseService` is used by the portal and `/api/v1/source-browser` controller. Saved source connection/project/step IDs are resolved and authorized before connector access. Tenant tokens need access to the source tenant; sink access alone is refused. Remote samples carry an expected Conduit instance ID. The browser calls source enumeration only, preserving saved source credential/class/include/exclude/filter/cap choices; it does not create sinks, run scripts, persist cursors or trigger sync.

`/source-catalog` lists local connections/projects plus metadata from configured IC connections. IC metadata is read through the existing saved API endpoint/key and tenant authorization. IC-owned rows open the configured `PortalUrl` in IC with exact connection/project parameters, so an IC-local CSV is read where its sync runs. The IC API does not attempt to open WebPortal-local source files. IC's catalog can sample remote Conduit sources through its existing ConduitClient transport. Redirects are disabled for credential-bearing catalog/browse HTTP; responses are size-bounded and credentials are per request.

Supported source reads: AD and CSV. Unsupported connectors stay visible with a reason. Connection browsing can narrow AD class/container/filter. Project browsing requires a saved enabled import step and uses its saved source scope. CSV browsing shows the saved file's rows before mapping/scripts. Samples are at most 200 rows, with loaded-sample search, paging, field tables, cancellation, explicit truncation and safe error states. No automatic discovery or fallback to another host.

Both consumer layouts load Brand primitives/list/table/browse assets directly from the shared project. `Verify-SourceBrowsingIntegration.ps1` checks the adapters, shared component composition and asset delivery, alongside Showcase/Brand architecture checks. The shared list action has token fallbacks when used outside a list container, fixing unreadable actions in the browser/catalog without product overrides.

Verification: 36 Conduit browse/catalog tests, seven IC catalog client tests, 25 IC browse/catalog tests and 58 reader/impact regressions passed, with zero failures/skips. Consumer builds passed with warnings; Showcase passed with zero warnings/errors. [Detailed receipt](../../_review/source-browsing-20260915/README.md). No live source/browser acceptance, migration, commit, publication or deployment occurred. Existing AD reader implementations remain separate; full shared engine hosting is not claimed.
