# Shared AD reader and mapping trials (CC-06/07)

Follow-up: [CC-08 reviewed mapping saves](IC-SHARED-MAPPING-SAVE.md) adds supported destination fields, sampled validation and explicit save/reload. The trial-only behavior below describes the CC-06/07 checkpoint; previews themselves still perform no writes.

Canonical source is `src/Conduit.Readers.ActiveDirectory`. IC references this project directly; it does not need a running Conduit server to read a local directory. Conduit's ActiveDirectorySource and IC's DirectoryQueryService use the same AdReader/LdapSession assembly. This library has no database, credential store, HTTP client, sink or scheduler.

The host resolves and authorizes the saved source, retrieves its own credentials, constructs/binds the LDAP connection and converts the resulting raw fields to its established value shapes. Conduit no longer borrows a differently named sink credential when the selected source credential is absent. Both host connections use bounded Negotiate binds and explicit naming contexts, without referral chasing. Existing connection-test/schema-discovery and Conduit deleted-object paths are separate; this change does not rewrite them.

The engine owns included/excluded container boundaries, subtree-base simplification, page controls, duplicate removal, raw values, ranged attribute continuation and completion evidence. Missing paging control, unresolved referral, repeated page, failed range continuation and cancellation are failures. A sample cap or early consumer exit does not establish a completed full read. Exact-cap reads may be complete only when every selected base has drained with a final empty cookie. Large multi-part `member` values are assembled before exposing a group.

[RFC 2696 section 3](https://www.rfc-editor.org/rfc/rfc2696.html#section-3) makes paging cookies opaque. The loop guard compares cookie plus page population, permitting an unchanged cookie when entries advance. Completion is not a point-in-time snapshot while AD is changing. Native LDAP requests have a 30-second bound; cancellation is checked before and after native work and at each page/range/record, but does not immediately interrupt an in-flight native call. A host's total sample timeout may therefore wait for that native call to return. DN containment handles case and escaped separator boundaries, not every equivalent textual DN representation.

`Conduit.SourceBrowsing` owns bounded mapping draft/results and display suppression. Each host adapter invokes the existing runtime field functions before display clipping: ConnectorMappingPlan for Conduit, AttributeMappingService for IC objects, and HRFieldTransformation/HRImportPlanning.Source for IC HR CSV. Host dialect/default/culture differences remain explicit. Project mappings come from the selected saved step; IC HR uses its existing connection fallback when a step has none.

IdentityCenter.Brand owns the single browser/editor/table and CSS. Browse data/Browse source ? load sample ? Use field or choose a sampled field ? set target/transformation ? Preview mappings. Preview rereads a bounded sample on the selected host. Saved mappings prefill the draft. It shows original and projected values, missing/null/default/omitted outcomes and hidden binary fields. Editing a rule invalidates its results; cancellation and old responses cannot restore them. An old host that lacks mapping results is refused. Known secret source/target fields cannot be revealed by renaming.

Trials do not save mappings, run scripts, validate target types, match identities, create a sink, persist cursors or change access. They preview field projection only; use the product's existing import/impact preview for full target and lifecycle decisions. Up to 200 sampled rows and 50 trial mappings are supported; saved rules excluded by sensitive-field or count limits are disclosed. Binary fields are explicitly not projected in this UI. No new migration.

Local build: coordinated latest Conduit, IC and IdentityCenter.Brand checkouts. Hosted builds must publish and pin the reviewed shared revisions first; do not invent a SHA for the current uncommitted tree. See IC `deploy/shared-conduit-build.md` and `Documentation/Quality/shared-ad-and-mapping-preview.md` for receipts and manual acceptance.
